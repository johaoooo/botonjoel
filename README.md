# Portfolio de Joel Boton — Maître Tisserand de Kanvô

> **Vitrine officielle et portfolio digital de Joel Boton**, maître artisan en tissage traditionnel et contemporain de **Kanvô** (pagne tissé traditionnel du Bénin) basé dans le quartier historique de Kandévié à **Porto-Novo, Bénin**.

---

## 🌟 Présentation du projet

Ce portfolio a été spécialement conçu pour valoriser le patrimoine textile béninois et les créations sur-mesure de Joel Boton :
- **Catalogue de créations** : Pagnes d'apparat, étoles nobles, décoration d'intérieur et pièces contemporaines avec motifs géométriques béninois.
- **Commande directe WhatsApp** : Chaque création et formule tarifaire dispose d'un lien direct avec message pré-rempli pour une conversion fluide.
- **Formations & Transmission** : Présentation des cursus d'initiation et de perfectionnement au métier à tisser traditionnel.
- **Visite de l'Atelier** : Mise en valeur du quartier historique de Kandévié et du travail 100% fait main.
- **FAQ complète** : Entretien du tissu, délais de tissage (3 à 7 jours), livraison nationale et internationale.

---

## 🛠️ Stack Technique

- **Framework** : [React 18](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Style** : CSS personnalisé avec charte sombre et reflets **Violet Améthyste** (`#9238F5` et `#C598FF`)
- **Typographie** : *Archivo* (titres percutants), *Inter* (lecture confortable), *Space Mono* (détails techniques)
- **Icônes** : [Lucide React](https://lucide.dev/) (icônes vectorielles épurées)
- **Responsive** : Optimisé pour mobile, tablette et écran large

## 🚀 Installation et Lancement local

1. **Cloner le dépôt** :
   ```bash
   git clone git@github.com:johaoooo/botonjoel.git
   cd botonjoel
   ```

2. **Installer les dépendances** :
   ```bash
   npm install
   ```

3. **Lancer le serveur de développement** :
   ```bash
   npm run dev
   ```
   L'application sera accessible sur `http://localhost:5173`.

4. **Compiler pour la production** :
   ```bash
   npm run build
   ```
